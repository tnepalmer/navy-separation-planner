# Navy Separation Planner

A free, personalized checklist and deadline timeline for sailors separating from the Navy.
Each person's info is saved only in their own browser. Not an official Navy product.

## Publish on GitHub Pages
1. Create a public repository and upload every file in this folder.
2. Settings, Pages, "Deploy from a branch", branch `main`, folder `/ (root)`.
3. The site appears at `https://<username>.github.io/<repository>/`.

## Updating
Replace `index.html`, and change `VERSION` in `sw.js` so installed copies pick up the change.
