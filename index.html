      Calendar reminders

      Get a reminder 7 days before each date and again on the day. The file adds two all-day entries per date to your calendar, which alerts you the way it does for any event.

      Google Calendar: Settings, then Import & export, then choose the file. Outlook: File, Open & Export, Import/Export, then “Comma Separated Values”. Download again if your dates change.

      Checklist

      Tick items off, and write what you've decided under “My plan”. Confirm anything Navy-specific with your CCC or CPPA.

        Your saved progress

        Restore your progress from a backup file or backup code you saved earlier.

        Everything saves automatically on this device each time you change something, and it is still here when you come back. It is not stored anywhere else, so save a backup file now and then. Use that file, or the backup code, to move to a new phone or computer.

        Found a mistake?

        Rules and phone numbers change. If something here is wrong or missing, report it so it gets fixed for the next sailor.
